# TAROT BREAKER 3D — 1000年前の星の国 visual prototype

このディレクトリは、Phase 2で成立確認した操作・会話・復帰ループを土台に、1000年前の**星の国**を3D空間として可視化する軽量Webプロトタイプ。

## CANON上の位置づけ

- 星の国：1000年前に実在した物理国家・文明・生活圏。
- 星界：想い・記憶・祈り・象徴・共鳴が交差する共同的精神位相。
- この3D空間は1000年前の**星の国**を描く。
- 回廊・遠景王都・浮遊構造の具体配置はビジュアル試作であり、国土全体の公式地理を確定しない。

## 体験骨格

**歩く → 記憶の場所を見つける → 会話する → 最後まで読む → 3D世界へ自然に戻る → また歩ける**

プレイヤーはシオン本人ではなく観測者。3D中は1000年前のシオンの視界を追体験する。

## Visual v1.1 — Immersive Star Country

Visual v1.0の「星の国らしい軽量3D」を、コンセプトイメージの方向へさらに近づける没入感パス。

- WebGLアンチエイリアスを有効化し、初期ポリゴン感を軽減。
- 星明／薄明の空をCanvasTexture化し、星雲・天の川・朝焼けを同じ空に共存させる。
- 近景星を別レイヤーにし、見上げたときにわずかな奥行きを作る。
- 箱型アーチを、QuadraticBezier + TubeGeometryの曲線リブへ変更。
- 側面に連続アーケードを追加し、回廊を単なる通路ではなく王域建築として見せる。
- 結晶をMeshPhysicalMaterial化し、透過・Clearcoat・内部発光で単色ポリゴン感を減らす。
- 床を磨かれた星紋石へ変更し、マーブル状の筋・淡金の幾何学紋・Clearcoatを追加。
- 花・葉の2.5Dスプライト、腰掛け、晶灯で「人が暮らしていた国」の気配を追加。
- 遠景を一つの王宮だけにせず、中央王域＋左右の浮遊区画＋橋＋滝＋雲の多層構成へ拡張。
- 王域の中央晶塔から淡い光柱を伸ばし、遠くても視線を導くランドマークにする。
- 空中の微光粒子を追加し、静かな光の流れを作る。
- 影・重いポストプロセスは使わず、ACES tone mapping / sRGB / DPR上限1.6でiPhone向け負荷を抑制。

## モバイル操作

- 仮想スティックは表示しない。
- 一本指：歩行・旋回。
- 二本指目：上下左右の自由視点。
- 視線補助はUI化せず、自由視点後に歩行すると上下だけゆっくり水平へ戻る。
- 歩行中のみ弱いヘッドボブ。OSの「視差を減らす」では無効。
- iOS Safariの文字選択、長押しコールアウト、ページスクロールはゲーム面で抑止。

## 記憶イベント

共鳴地点はUI用ダイヤではなく、星の国に存在する結晶群＋微光粒子として表示する。

- 初回：会話枠タップで進行。
- AUTO：初回から利用可能。
- SKIP：完読済みの記憶の再読時のみ。
- 最後のセリフ後は短い余韻を置いて3Dへ戻る。
- 途中退出は「記憶から離れる」。

## 離脱・復帰

無操作タイマーは使わない。復帰画面はタブ切替、別アプリ移動、bfcache復帰、WebGL context loss時のみ。

## 検証上の注意

Visual v1.1は高精細GLB・正式テクスチャ投入前の**軽量アート方向検証**。完成品質を保証するものではない。

iPhone実機では、見た目だけでなく以下も確認する。

- 入った瞬間に「技術試作」より「星の文明」が先に感じられるか。
- 上を見たくなる建築・空になったか。
- 中央王域だけでなく左右にも国が続く感覚があるか。
- 結晶・光・床が過度に発光せず、重要地点が埋もれないか。
- 歩行・会話・視点操作に支障がないか。
- カクつき、発熱、描画欠けが許容範囲か。

Three.js 0.180.0を同梱。新規Service WorkerやCache API操作は追加しない。
