# TAROT BREAKER 3D — Phase 2 prototype

実行基準はユーザー指定の **Astra Phase 2 v1.1**。最上位の世界観仕様は `../../docs/tarot-breaker-3d-spec-v0.3.md`。Phase 3以降へは進まない。

## Phase 2の意味

この試作はゲーム本編を完成させるためのものではない。

検証する最小体験は、次の1ループだけ。

**歩く → 記憶の場所を見つける → 会話する → 最後まで読む → 3D世界へ自然に戻る → また歩ける**

プレイヤーはシオン本人ではなく「観測者」。3D中は1000年前のシオンの視界を追体験する。

将来は同じ構造で、場所・時代・人物ごとに記憶イベントを追加し、星界そのものへ物語を蓄積していく。Phase 2ではその拡張を作らず、1つの記憶で体験ループが成立するかだけを確認する。

## v1.8 — Immersion pass

実機検証用の説明文・操作チュートリアルが体験より前に出ていたため、ユーザー向け画面から検証説明を撤去した。

- 冒頭は世界観の一文と「星界へ」だけにする。
- 常時表示の操作説明を廃止する。
- 操作はゲーム面そのものへのジェスチャで成立させる。
- 通常時のガイド文は表示せず、記憶地点でだけ短い世界観表現を出す。
- 完読後の通知もシステム説明ではなく、短い物語表現にする。

内部READMEとPRには検証目的を残すが、プレイヤーへ「試験導入」「Phase 2」「操作方法」を読ませない。

## v1.9 — Free-look polish

`自動視点 ON/OFF` は、実際には上下視線を水平へ戻す補助だけで、機能名と体感が一致していなかったためプレイヤー向けUIから撤去した。

視点操作は次の自然挙動へ統合する。

- 一本指：歩行・旋回。
- 二本指目：上下左右の自由視点。見上げる／見下ろす／周囲を見るために使う。
- 自由視点中は視線補正を行わない。
- 二本指を離した直後も約1.2秒は見ていた方向を保持する。
- その後、歩行している場合だけ上下視線をゆっくり水平へ戻す。
- 左右の向きは自動補正しない。プレイヤーが向いた方向を維持する。
- 上下可動域は約±60度とし、星空や床・建築を見回せるようにする。

視線補正は設定として意識させず、歩行時の自然な補助として裏側で動作させる。

## モバイル操作

- 仮想スティックは表示しない。
- 一本指を上へ押し出すと前進、下へ動かすと後退。
- 左右への指移動は横滑りではなく、シオンの身体と視界をその方向へ旋回させる。
- 前進しながら左右へ動かすと、曲がりながら歩く。
- 指を離すと停止する。
- 二本目の指で上下左右を自由に見回せる。
- 歩行中だけ弱いヘッドボブを使い、OSの「視差を減らす」設定では無効化する。
- iOS Safariの文字選択、長押しコールアウト、ページスクロールをゲーム面では抑止する。

## 記憶イベント

正面の光へ近づくと移動を停止し、「ふたりに声をかける」を表示する。

会話は共有スキットエンジンを再利用する。3D版ではスタンドアロン版の終了・次エピソードボタンを表示しない。

- 会話途中：会話枠タップで次へ。
- 最後のセリフ：もう一度会話枠をタップすると短い余韻の後に3Dへ戻る。
- `AUTO`：初回から利用可能。終端では読み時間を置いて自動復帰する。
- `SKIP`：完読済みの記憶を再読するときだけ表示する。
- 途中退出：上部の「記憶から離れる」で行う。
- 完読済み地点：再度「もう一度、記憶に触れる」で再読できる。

## 離脱・復帰

「ひと休み／復帰」相当の画面に**無操作タイマーは使わない**。

表示トリガーは以下だけ。

1. タブ切替・ホーム画面・別アプリ移動などで `document.hidden` になった場合。
2. bfcacheからページへ復帰した場合。
3. WebGL context lossが発生した場合（この場合だけ技術的な復旧案内を出す）。

会話中にバックグラウンドへ移動しても会話セッションは破棄せず、復帰後は同じ会話へ戻す。

## 構成

`data/` は仮マップ・イベント・キャラクター。`js/state.js` はDOM非依存の位置・視点・イベント状態。`input.js` は入力、`world.js` は描画、`skit-bridge.js` は既存エンジン接続と3D用の記憶終了フロー、`audio.js` は単一音源、`app.js` はライフサイクルを所有する。

既存 `skits/skit_005.json`（全8ノード）を原文のまま使用。キャラクター3人は会話で表示し、3Dの光は会話地点の仮マーカー。人物の姿を置き換えたものではない。

## 検証

jsdomは実ブラウザ・GPU・実機操作・聴取の代用ではない。iPhone実機の操作感と没入感を最終受入基準とする。

- WebGL 2必須、設計対象はiOS/iPadOS Safari 16.4以上および現行Android Chrome／PCブラウザ。
- DPR上限1.5。影・ポストプロセスなし。
- 版固定のThree.js 0.180.0を同梱。
- 新規Service WorkerやCache API操作を追加しない。
- 独自資産のキャッシュ識別は `v=p2-1.9.0`。

受入条件・判定・未検証項目は `../../docs/tarot-breaker-3d-phase2-report.md` を参照。
