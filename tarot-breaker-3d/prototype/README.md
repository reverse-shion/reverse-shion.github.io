# TAROT BREAKER 3D — Phase 2 prototype

実行基準はユーザー指定の **Astra Phase 2 v1.1**。最上位の世界観仕様は `../../docs/tarot-breaker-3d-spec-v0.3.md`。Phase 3以降へは進まない。

## Phase 2の意味

この試作はゲーム本編を完成させるためのものではない。

検証する最小体験は、次の1ループだけ。

**歩く → 記憶の場所を見つける → 会話する → 最後まで読む → 3D世界へ自然に戻る → また歩ける**

プレイヤーはシオン本人ではなく「観測者」。3D中は1000年前のシオンの視界を追体験する。

将来は同じ構造で、場所・時代・人物ごとに記憶イベントを追加し、星界そのものへ物語を蓄積していく。Phase 2ではその拡張を作らず、1つの記憶で体験ループが成立するかだけを確認する。

## モバイル操作 v1.7

- 仮想スティックは表示しない。
- 一本指を上へ押し出すと前進、下へ動かすと後退。
- 左右への指移動は横滑りではなく、シオンの身体と視界をその方向へ旋回させる。
- 前進しながら左右へ動かすと、曲がりながら歩く。
- 指を離すと停止する。
- 二本目の指で自由視点を調整できる。
- `自動視点 ON/OFF` を右上に配置。ONでは歩行中の上下視線を自然に水平へ戻す。
- 歩行中だけ弱いヘッドボブを使い、床の上を滑る感覚を抑える。OSの「視差を減らす」設定では自動的に無効化する。
- iOS Safariの文字選択、長押しコールアウト、ページスクロールをゲーム面では抑止する。
- PCはWASD／矢印、マウスドラッグ、Eで会話。

## 記憶イベント v1.7

正面の光へ近づくと移動を停止し、「ふたりと話す」ボタンを表示する。

会話中は、共有スキットエンジンの既存会話・表情・ログ・Autoを再利用する。ただし3D版では、スタンドアロン版の「次のエピソードへ」「会話を終える」ボタンは表示しない。

最後のセリフまで到達したら、**もう一度会話枠をタップすると約0.4秒の余韻を置いて3Dへ自動復帰**する。途中で退出したい場合だけ、上部の「記憶から離れる」を使用する。

完読した記憶は、同じ場所で「もう一度この記憶を見る」として再読できる。

## 構成

`data/` は仮マップ・イベント・キャラクター。`js/state.js` はDOM非依存の位置・視点・イベント状態。`input.js` は入力、`world.js` は描画、`skit-bridge.js` は既存エンジン接続と3D用の記憶終了フロー、`audio.js` は単一音源、`app.js` はライフサイクルを所有する。

既存 `skits/skit_005.json`（全8ノード）を原文のまま使用。キャラクター3人は会話で表示し、3Dの光は会話地点の仮マーカー。人物の姿を置き換えたものではない。

## 検証

jsdomは実ブラウザ・GPU・実機操作・聴取の代用ではない。iPhone実機の操作感を最終受入基準とする。

- WebGL 2必須、設計対象はiOS/iPadOS Safari 16.4以上および現行Android Chrome／PCブラウザ。
- DPR上限1.5。影・ポストプロセスなし。
- 版固定のThree.js 0.180.0を同梱。
- 新規Service WorkerやCache API操作を追加しない。
- 独自資産のキャッシュ識別は `v=p2-1.7.0`。

受入条件・判定・未検証項目は `../../docs/tarot-breaker-3d-phase2-report.md` を参照。
