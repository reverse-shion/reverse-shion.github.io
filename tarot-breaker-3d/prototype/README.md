# TAROT BREAKER 3D — Star Country visual prototype

Phase 2で、iPhone上の最小体験ループ

**歩く → 記憶の場所を見つける → 会話する → 最後まで読む → 3D世界へ自然に戻る → また歩く**

の操作・会話・復帰を成立確認した。本ディレクトリはその骨格を維持したまま、仮3D空間を**1000年前の星の国**へ置き換えるビジュアル試作へ移行する。

> ブランチ名 `feature/tarot-breaker-3d-phase2-prototype` はPhase 2から継続した履歴名。現在の物理舞台名称はCANONに従い「1000年前の星の国」とする。

## CANON境界

- 星の国：1000年前に実在した物理国家・文明・生活圏。
- 星界：想い・記憶・祈り・象徴・共鳴が交差する共同的精神位相。
- 1000年前にも両者は並存する。
- 王宮・門・民・文化の実在は確定する。
- 惑星固有名、国土全体の地図、地理座標、国土規模は未確定。
- この試作の座標、回廊配置、遠景王宮、浮遊構造、仮称を公式地理として固定しない。

## Visual v1.0 — 1000年前の星の国

現在の1エリアを「王域外郭回廊」の**ビジュアル試作**として再構築する。名称自体は仮称。

### アートコア

**星空そのものが建築になった国。**

普通の石造都市に水晶を置くのではなく、星・光・結晶・観測・共鳴が文明と建築へ溶け込んだ物理国家として描く。

### 実装済み

- 深夜固定ではない「星明／薄明」系の空色グラデーション
- 星空・星座線・微細な回転による生きた空
- 白銀石・淡金・群青・ラベンダーを基調とするマテリアル
- 星紋と円環を持つ磨かれた回廊床
- 白銀の高柱と簡易尖塔アーチ
- 道沿いの晶柱・結晶群
- 生活空間を示唆する低い腰掛け
- 遠景の王域中枢／晶塔シルエット
- 遠景の浮遊岩・晶片（地理CANONにはしない）
- 仮の八面体イベントマーカーを廃止し、共鳴晶＋星粒へ置換
- 王域側の門と星晶バナー
- スマホ負荷を抑えるため、影・ポストプロセス・高精細GLBを使わず形・光・奥行きで密度を作る

## 操作

- 一本指：歩行・旋回。
- 二本指目：上下左右の自由視点。
- 自由視点後は見ていた方向を短時間保持し、歩行中のみ上下視線を自然に水平へ戻す。
- 仮想スティックや常時チュートリアルは表示しない。
- 歩行中だけ弱いヘッドボブを使い、`prefers-reduced-motion` では無効化する。

## 記憶イベント

共鳴晶へ近づくと移動を止め、「ふたりに声をかける」を表示する。

- 初回：会話枠タップ／AUTOで進行。
- 最後：手動は最後の会話枠タップ、AUTOは読み時間後に3Dへ自動復帰。
- 再読時だけSKIPを表示。
- 途中退出のみ「記憶から離れる」。
- 3D版では「会話を終える」「次のエピソードへ」を表示しない。

## 離脱・復帰

復帰画面に無操作タイマーは使わない。タブ切替・別アプリ移動・bfcache復帰・WebGL context lossだけを契機とする。

## 技術方針

- Three.js 0.180.0を同梱利用。
- WebGL 2前提。
- DPR上限1.5。
- 高品質モデルを大量投入する前に、軽量ジオメトリ・Sky shader・CanvasTexture・限定数の光源・粒子でアート方向を検証する。
- 正式GLB／テクスチャは、王宮・星門・象徴的晶柱など重要アセットから段階的に置き換える。
- 新規Service WorkerやCache API操作は追加しない。
- Visual v1.0の独自キャッシュ識別は `star-country-v1.0`。

## 次の判断

このVisual v1.0は完成版ではない。iPhone実機で次を確認する。

1. 入った瞬間に「灰色の試験空間」ではなく「星の文明」に見えるか。
2. 星空、建築、結晶を二本指で見上げたくなるか。
3. 遠景王宮によって世界がこの1エリアの外にも続いていると感じるか。
4. 共鳴晶がUIマーカーではなく世界の一部として読めるか。
5. 描画負荷、発熱、操作レスポンスが許容範囲か。

合格後に、正式3Dアセット制作と複数エリア化へ進む。
