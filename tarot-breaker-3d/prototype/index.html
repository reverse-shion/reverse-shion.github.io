TAROT BREAKER · MEMORY

1000年前の
シオンの記憶

これは、あなた自身がシオンになる物語ではありません。
星に残された記憶をたどり、観測者としてシオンの視界を追体験します。

一本指を上へ押し出すように動かすと前へ歩きます。
歩きながら左右へ動かすと、その方向へ身体ごと曲がります。左右だけならその場で向きを変えます。指を離すと停止します。

正面の光へ進むと、しおぽんとリュミエールに話しかけられます。

一時停止

記憶の追体験を一時停止しました。
