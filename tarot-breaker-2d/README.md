# TAROT BREAKER — 1000年前の星の国 2D探索プロトタイプ

## 目的
ユーザー提供の正式候補マップとシオンのドット素材を使い、
「星の国の中をシオンとして歩ける」最小体験を確認するための独立プロトタイプ。

## v0.1.1
- 1000年前の星の国・星門庭園マップをゲーム背景として使用
- シオンの4方向・8コマ歩行スプライトをゲーム用に抽出
- スマホ／iPad向けドラッグ式バーチャルスティック
- PC向け WASD / 矢印キー
- シオン追従カメラ
- マップ外・主要な崖への簡易衝突判定
- 開始地点へ戻るボタン
- 軽い星粒演出
- Safari向けに明示的なスタート画面を追加
- 実機テスト用に画像を軽量化
- 会話・NPC・Pamera・時代分岐はまだ未実装

## 操作
スマホ / iPad:
「星の国へ」を押したあと、画面左側を押した位置から指をスライド。

PC:
WASD または矢印キー。
