# TAROT BREAKER 3D — Phase 2 実装・検証レポート

実行基準：ユーザー指定「Astra Phase 2 実行仕様書 v1.1」。作業日：2026-09-11〜12 UTC。

**現在の判定：HOLD — IPHONE MOBILE RETEST REQUIRED。** 初回実装はiPhone実機の操作性で不合格。mainへのマージ、本番公開、Phase 3開始は行わない。

対象リポジトリは `reverse-shion/reverse-shion.github.io`。既存ブランチ `feature/tarot-breaker-3d-phase2-prototype` を継続使用する。

## 1. 現在の実装概要

入口：`tarot-breaker-3d/prototype/index.html`。

1000年前の星界を、観測者であるユーザーが「シオンの記憶」として一人称視点で追体験する。正面の光へ到達すると既存 `skit_005` を使ったシオン・しおぽん・リュミエールの会話へ入り、終了後は同じ位置・向きへ戻る。

ユーザー自身がシオンになる設定ではない。メタ視点は「星に残された記憶をたどる観測者」、ゲーム中の映像は「1000年前のシオンの視界」とする。この二層構造を、将来複数の時代・人物・記憶を追加していける『終わらない物語』の基盤とする。

## 2. iPhone実機で判明した問題

初回版〜v1.4の実機確認で以下を確認した。

- 固定／画面分割型の仮想スティックが直感的でない。
- Safariが長押しを文字選択として扱い、コピー／検索／翻訳UIが出ることがあった。
- 直進自体は改善したが、指操作中だけ前進する感覚が強く、小刻みで滑らかさに欠けた。
- 「左＝移動／右＝視点」というルールを初見で理解しづらい。
- 一人称がユーザー本人の視点に見え、シオン視点であることが伝わりづらかった。

## 3. モバイル操作 v1.5

画面分割型を廃止し、ゲーム画面全体をスワイプ操作面とする。

- 仮想スティックは表示しない。
- 画面のどこでも、上スワイプ＝前進、下＝後退、左／右＝横移動。
- スワイプ方向は上下左右4方向へ確定し、指の微妙な横ブレを斜行へ変換しない。
- スワイプ完了後も移動状態を保持し、毎フレーム同じ速度で連続歩行する。
- 画面を1回タップすると停止。
- 光のイベント範囲へ入った場合は自動停止して会話へ遷移。
- 二本目の指を同時にドラッグした場合のみ手動視点調整。
- iOS Safariの文字選択、長押しコールアウト、ページスクロールをゲーム面で抑止する。
- PCはWASD／矢印、マウスドラッグ、Space停止、E会話を維持する。

移動速度は3.2。視点揺れ・歩行ボブは採用していない。

## 4. 視点追尾 ON/OFF

一人称視点なので、三人称ゲームのようにキャラクター後方へカメラを追尾させる方式ではない。

- `視点追尾 ON`（初期値）：移動中、上下方向へずれた視線を滑らかに水平へ戻す。
- `視点追尾 OFF`：現在の視線角度を保持する。
- 手動視点調整は二本指ドラッグで行う。

この機能は一人称の「視線アシスト」であり、シオンの視界を維持したまま操作負荷を減らすためのもの。

## 5. 既存資産と技術

- Three.js 0.180.0 / r180 を同梱。
- 静的HTML/CSS/ES Modules。バックエンド、API、DBなし。
- 既存 `skit_005` 全8ノード、既存表情10枚、既存BGM `audio/seifu-raguna.mp3` を再利用。
- 会話終了・途中退出・読込失敗・タブ中断から復帰できる既存Bridge構造を維持。
- キャッシュ識別は `p2-1.5.0`。

## 6. v1.5 実機受入項目

1. 画面の場所を意識せず上へスワイプすると前進が始まる。
2. 指を離した後も小刻みにならず滑らかに前進を継続する。
3. 1回タップすると即座に停止する。
4. 左右スワイプで斜行せず左右移動する。
5. 視点追尾ON/OFFが切り替わる。
6. Safariの文字選択UIが出ない。
7. 光へ到達すると移動停止→会話開始する。
8. 会話終了後にゲームへ戻れる。
9. BGMが開始される。

## 7. 検証上の注意

クラウドブラウザではWebGLが無効だったため、3Dの実表示・iPhoneの指操作・実音・発熱・FPSはクラウド検証の代替ができない。iPhone実機の操作感を最終受入基準とする。

自動テストは状態遷移・衝突・既存スキット・非同期読込・音状態などの回帰確認には使えるが、指で触ったときの自然さを合格扱いするものではない。

## 8. 停止点

v1.5をiPhone実機で再確認するまでPhase 2はHOLD。操作感が自然でなければPhase 2内で再修正する。mainへのマージ、本番公開、Phase 3開始はそれぞれ別の明示判断とする。
